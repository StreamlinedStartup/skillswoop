# The Library is a built-in source that cannot be removed

Skills added from the person's own machine and skills moved out by Tidy both land in the Library, and the Library behaves like any other Source: browse it, install from it, star its skills. It cannot be removed, which avoids deciding whether removing it would delete the skills inside. A Name clash in the Library is never resolved silently: swoop refuses, tells the person, and lets them choose which of the two skills to Rename.
